CS 1.6 ScoutzKnivez Server

Containerized Counter-Strike 1.6 scoutzknivez server using the ReHLDS stack

// Install

curl -fsSL https://raw.githubusercontent.com/KevinTCoughlin/cs-server/main/install.sh | bash

Requires Podman (rootless) or Docker. The script pulls the image from ghcr.io, writes config files to ~/.config/cs-server/ (including a random RCON password), and starts the server on port 27015. With Podman it installs a systemd Quadlet unit; with Docker it creates a container with a restart policy.

// Quick Connect

Console Command
connect <your-ip>:27015

Default port: 27015 (UDP + TCP). Replace <your-ip> with your server's LAN or public IP.

// Ready Before the Holiday Break

Christmas, New Year, winter or summer holidays: wherever you are, the break is when everyone is finally in one place. Set it up once for a LAN night with family and friends.

  1. Install it on a spare Linux machineRun the install command above on any box with Podman or Docker. The three ScoutzKnivez maps are in the image, so there is nothing else to download.
  2. Everyone connects from the CS 1.6 consoleOpen the console and type connect <server-lan-ip>:27015. The installer prints the address when it finishes.
  3. Keep it to the houseFor a LAN-only night with the Podman install, change Environment=LAN_MODE=0 to 1 in ~/.config/containers/systemd/scoutzknivez.container, then run systemctl --user daemon-reload && systemctl --user restart scoutzknivez.
  4. Or let friends join from their housesLeave LAN_MODE=0 (the default), allow 27015 UDP and TCP through the host firewall, forward it on your router, and share your public IP.
  5. Only two of you? Bots fill inZBots fill the server up to 10 players and leave as people join, so even a small group gets a full round. Set BOTS=0 to turn them off.
  6. Switch it upType rtv in chat to vote for a new map. For classic Dust 2, set MAP=de_dust2 and MAPCYCLE=mapcycle-dust2.txt in the same unit file and restart.

// Quick Start

Option 1: Pull from ghcr.io (fastest — pre-built image)

$ podman pull ghcr.io/kevintcoughlin/cs-server:latest
$ podman run -d -p 27015:27015/udp -p 27015:27015/tcp \
  --name scoutzknivez ghcr.io/kevintcoughlin/cs-server:latest

Option 2: Build from source (if you need custom maps/configs)

  1. Clone the repository
  2. Optional: add custom .bsp maps to maps/. The default ScoutzKnivez maps are already bundled from docs/cstrike/maps/
  3. Build and launch the server
$ git clone https://github.com/KevinTCoughlin/cs-server.git
$ cd cs-server
# optional: copy custom .bsp maps into maps/
$ podman compose up --build

// Bots

Bots are enabled by default using ReGameDLL_CS's built-in ZBot support. Bots fill the server up to 10 players and leave as humans join — no human player required to start.

// Windows (WSL2)

Docker Desktop for Windows cannot reliably forward UDP game traffic. Run the server inside a WSL2 Debian distro with Podman or Docker CE instead.

  1. Install Debian: wsl --install Debian
  2. Install dependencies (i386 libs, curl, unzip)
  3. Install Podman or Docker CE in the distro, then run the install script inside WSL2
  4. Find WSL2 IP: ip addr show eth0
  5. Connect from Windows: connect <wsl2-ip>:27015

See README for full instructions. Related: #18

// Production (Quadlet)

Run as a rootless Podman Quadlet unit managed by systemd for auto-start, crash recovery, and graceful shutdown. The one-line installer sets this up with the prebuilt image. From a clone, with a locally built image:

$ podman compose up --build -d && podman compose down
$ mkdir -p ~/.config/cs-server && cp config/server.cfg config/mapcycle*.txt ~/.config/cs-server/
$ just install  # copies the unit, runs daemon-reload
$ systemctl --user start scoutzknivez

To start on boot, run loginctl enable-linger for your user.

On shutdown, players see a 30-second countdown before the server stops cleanly.

Custom maps (and Quake sounds, if you add them) are served from this site via HTTP for fast client downloads. The repository's config/server.cfg, which is also baked into the image, sets sv_downloadurl to this URL. The one-line installer writes its own server.cfg without it, so add the line there if you want FastDL.
