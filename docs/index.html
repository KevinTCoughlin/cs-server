Your own low-gravity CS 1.6 server, up in one command.

Scouts, knives and bunny hops on a containerized ReHLDS stack. Bots fill the empty slots, so the first round starts the moment you connect, whether that's a LAN night or a box in your homelab.

$ curl -fsSL https://raw.githubusercontent.com/KevinTCoughlin/cs-server/main/install.sh | bash

Needs Podman or Docker. Pulls the prebuilt image and starts the server on port 27015.

$ brew install just container && container system start && git clone https://github.com/KevinTCoughlin/cs-server.git && cd cs-server && just up-d

Builds from source with Apple's container CLI (about 10 minutes the first time). How it runs on a Mac.

    What you get

    A full ScoutzKnivez server, already tuned

    Everything is configured in the image. You don't hunt for plugins, compile anything or edit a config to get a good first round.

    Low gravity, high air control

    sv_gravity 240, sv_airaccelerate 100, no freeze time, no buy menu. Everyone spawns with a scout and a knife, and holding jump bunny hops.

    Bots that make room

    ZBots keep 10 players in the game and leave as people join, so two friends still get a full server. Set BOTS=0 to turn them off.

    Players pick the map

    Type rtv in chat to start a vote and nominate to add a map. Three ScoutzKnivez maps ship in the image, with classic Dust 2 one variable away.

    Nipper Friday

    A knife-only mode on NIPPER's classic maps. just mode nipper switches at the end of the round, with no restart. How it works.

    Locked down by default

    Runs as a non-root user on a read-only filesystem with every Linux capability dropped, no privilege escalation, and memory and CPU limits. Network RCON is off unless you turn it on.

    Stays up on its own

    A systemd Quadlet unit on Linux or a launchd agent on macOS starts it at boot and restarts it after a crash. On shutdown, players get a 30-second countdown.

    Classic and 5v5 match modes

    just mode vanilla is stock Counter-Strike. just mode match runs a 5v5: warmup, .ready, a knife round for sides, and .pause. The modes.

    Seven more games

    The same server for Condition Zero, Day of Defeat, Team Fortress Classic, Half-Life deathmatch, Opposing Force, Deathmatch Classic and Ricochet: CS_GAME=dod. Other games.

    More than one server

    CS_INSTANCE=match2 CS_PORT=27016 adds a second server on the same machine with its own settings, bans and stats. CS_LAN_KIT=4 sets up four match servers for an event in one go. LAN kit.

    Install

    Three steps to the first round

    On Linux the installer does the work. It pulls the image from ghcr.io, writes configs to ~/.config/cs-server/ with a random RCON password, and starts the server.

    1. Run the installer

      On any Linux machine with Podman or Docker.

      $ curl -fsSL https://raw.githubusercontent.com/KevinTCoughlin/cs-server/main/install.sh | bash

    2. Open the port (optional)

      For friends outside your network, allow 27015 UDP and TCP on the host and forward it on your router. Skip this for LAN play.

    3. Connect from CS 1.6

      Open the console in the game and type the address the installer printed.

      connect <your-ip>:27015

    Prefer to do it by hand? podman run -d -p 27015:27015/udp --name scoutzknivez ghcr.io/kevintcoughlin/cs-server:latest, or clone the repo and run podman compose up --build.

    LAN night checklist Holiday break or any weekend

    The break is when everyone is finally in one place. Set it up once.

    1. Install it on a spare Linux machine. Run the install command on any box with Podman or Docker. The three ScoutzKnivez maps are in the image, so there is nothing else to download.
    2. No spare Linux box? Use your Mac. Apple silicon Macs run it with Apple's container CLI: just build && just up from a checkout. See macOS / Apple silicon.
    3. Everyone connects from the CS 1.6 console. Type connect <server-lan-ip>:27015. The installer prints the address when it finishes.
    4. Keep it to the house. Run the installer with CS_PROFILE=lan in front of bash. The server then shows up in everyone's LAN tab and needs no internet connection.
    5. Or let friends join from their houses. Leave LAN_MODE=0 (the default), allow 27015 UDP through the host firewall, forward it on your router, and share your public IP.
    6. More than ten of you? CS_LAN_KIT=3 installs three match servers on ports 27015 to 27017 and serves the maps from the same machine. See LAN kit.
    7. Only two of you? Bots fill in. ZBots fill the server up to 10 players and leave as people join. Set BOTS=0 to turn them off.
    8. Make Friday a Nipper Friday. Knives only on NIPPER's classic maps, with his Christmas maps through Jan 6. See Nipper Friday.
    9. Switch it up. Type rtv in chat to vote for a new map. For classic Dust 2, set MAP=de_dust2 and MAPCYCLE=mapcycle-dust2.txt in the same unit file and restart.

    Game modes ScoutzKnivez, knife, vanilla, 5v5 match, climb, surf

    One server, six modes. just mode <name> switches at the end of the round with no restart; MODE picks the one it starts in.

    ModeWhat it is
    scoutzThe default: scout and knife in low gravity, with bunny hop.
    nipperKnives only on NIPPER's maps (MODE=knife). See Nipper Friday.
    vanillaStock Counter-Strike: normal gravity, buying, bombs and hostages, $800.
    matchA 5v5 match, first to 16 of 30 rounds, sides swapped after 15.
    climbKZ maps with a run timer, checkpoints (/cp, /tp) and a top 15 per map (/top). Stock physics, no rounds, no bots.
    surfSurf maps: air acceleration 100, no fall damage, runs timed between a start and an end zone.

    A match goes through four steps on every map:

    1. Warmup. Everyone respawns with full money and rounds do not end. Players say .ready.
    2. Knife round. Starts when ten players are ready. Knives only, one round.
    3. Sides. The winners say .stay or .switch within 30 seconds.
    4. Live. .pause holds the next freeze time until someone says .unpause.

    For a 2v2, set match_players 4 in modes/match.cfg. To practise with bots, just rcon "match_start" skips the ready-up. There is no overtime: 15-15 is a draw.

    LAN kit Several match servers and local map downloads

    For an event with more players than one server holds. One command installs the servers, puts them in the LAN tab and serves their maps from the same machine, so nothing depends on the internet.

    $ curl -fsSL https://raw.githubusercontent.com/KevinTCoughlin/cs-server/main/install.sh | CS_LAN_KIT=4 bash
    1. Four servers. lan1 to lan4 on ports 27015 to 27018, each with its own settings, bans and stats. Any number from 1 to 8.
    2. Match mode, no bots. Each starts in the 5v5 match mode. CS_MODE=vanilla or scoutz and CS_BOTS=1 change that.
    3. Maps over HTTP. A small web server from the same image hands maps to players on port 27080, much faster than the game connection. It serves maps and assets only: no settings, no admin files.
    4. Open the ports. The game ports (UDP) and 27080 (TCP) in the machine's firewall.
    5. Afterwards. The same command with --uninstall removes all of them.

    Just want the map server next to one ordinary server? CS_FASTDL=1 adds it to any install. The LAN tab only looks at a few ports above 27015; players reach a server on a higher port with connect <address>:<port>.

    Metrics Players, map and server FPS for Prometheus

    Every server keeps count of players and bots, the running map, uptime and its own frames per second, in Prometheus format. The numbers come from the game itself, so they are there for a LAN-only server too. Nothing listens until you ask for a port:

    $ curl -fsSL https://raw.githubusercontent.com/KevinTCoughlin/cs-server/main/install.sh | CS_METRICS_PORT=9137 bash
    $ curl -s http://127.0.0.1:9137/metrics
hlds_players{type="human"} 3
hlds_players{type="bot"} 7
hlds_map_info{map="scoutzknivez"} 1
hlds_server_fps 870.4
hlds_up 1

    The port is published on the machine's own loopback address only; CS_METRICS_BIND names another. There is no login on it, so keep it off the internet. Without a port, podman exec scoutzknivez cat /hlds/.runtime/metrics.prom shows the same numbers.

    Nipper Friday Knife-only mode on NIPPER's maps

    Back in the day, Friday nights meant knife fights on NIPPER's custom maps: a house you could actually explore, grenade dodgeball in a gym, a hamster cage floating in space. Nipper Friday brings that back as a knife-only mode on NIPPER's own map pack, without touching the everyday ScoutzKnivez setup.

    1. Knives only. No scout, no buying, no picking up weapons, normal gravity. On grenade maps like he_dodgeball2, you can pick up the HE grenades the map lays out.
    2. The rotation. nipperhouse, ka_beams, nippers100, he_dodgeball2, hamsters and de_westwood. From Dec 1 to Jan 6: xmas_nipperhouse, x-mas_tree, xmas_lodge and xmas_crazytank.
    3. No restart. just mode nipper (or scoutz) announces the switch in chat and changes map at the end of the round, so nobody gets cut off mid-fight.
    4. Every Friday, if you want. just friday-enable turns it on Friday at 17:00 and off Saturday at 04:00, local time. It does nothing while the server is off and never restarts it.
    5. Get the maps. just fetch-maps && just build downloads NIPPER's pack once from GameBanana, checks its SHA-256, and builds in only the maps it uses.

    Credit: maps by Nathaniel Miller (NIPPER), released under CC BY-NC-ND 4.0. This project doesn't re-host them: they aren't in the repository, the published images or the FastDL below. Each server downloads them from NIPPER's own upload, and players get them from that game server. They're played unmodified, free and non-commercially, with NIPPER credited in-game.

    macOS / Apple silicon Apple container + qemu-i386

    Runs under Apple container. Rosetta only translates x86_64 and HLDS is 32-bit i386, so the Mac image is arm64 and runs the server under qemu-i386 user-mode emulation (~250 server FPS with 10 bots on an M-series Mac).

    1. Install: brew install container && container system start
    2. Build (~10 min, from source): just build
    3. Run: just up, or as a launchd agent: just install
    4. Connect: connect <mac-ip>:27015

    See the README for details.

    Windows (WSL2) Skip Docker Desktop for game traffic

    Docker Desktop for Windows cannot reliably forward UDP game traffic. Run the server inside a WSL2 Debian distro with Podman or Docker CE instead.

    1. Install Debian: wsl --install Debian
    2. Install dependencies (i386 libs, curl, unzip)
    3. Install Podman or Docker CE in the distro, then run the install script inside WSL2
    4. Find the WSL2 IP: ip addr show eth0
    5. Connect from Windows: connect <wsl2-ip>:27015

    See the README for full instructions. Related: issue 18.

    Production (Quadlet) systemd, crash recovery, graceful shutdown

    Run as a rootless Podman Quadlet unit managed by systemd. The one-line installer sets this up with the prebuilt image. From a clone, with a locally built image:

    $ podman compose up --build -d && podman compose down
$ mkdir -p ~/.config/cs-server && cp config/server.cfg config/mapcycle*.txt ~/.config/cs-server/
$ just install  # copies the unit, runs daemon-reload
$ systemctl --user start scoutzknivez

    To start on boot, run loginctl enable-linger for your user. On shutdown, players see a 30-second countdown before the server stops cleanly.

    FastDL Fast map downloads for clients

    Custom maps (and Quake sounds, if you add them) are served from this site over HTTP for fast client downloads. That is this project's own server. A server you install sends custom content itself until you set FASTDL_URL (container environment, or on the installer's command line) to a host that serves your cstrike/ files, or run the installer with CS_FASTDL=1, which serves them from the same machine (see LAN kit). NIPPER's maps aren't served here (see Nipper Friday).
